
# 💌 Secret Letter

A little letter, a little courage, and a heart that wants to tell you something. 💗

## 🌷 About This Project

**Secret Letter** is a simple romantic website created to express feelings through a digital letter.

This website is dedicated to someone special, Syifa, from Giii. It contains a sweet opening message, an animated envelope, a personal letter, and a special question with two choices: **Yes** or **No**.

Every interaction is designed to make the experience feel more personal, sweet, and memorable.

## ✨ Features

- 💌 Animated opening envelope.
- 💗 Romantic pink-themed design.
- 📝 Personal digital love letter.
- 🌸 Smooth animations and floating hearts.
- 🥺 Interactive Yes and No buttons.
- 💞 Yes button grows when No is clicked.
- ❤️ Special ending for the Yes choice.
- 🌷 Respectful ending for the No choice.
- 📱 Responsive design for mobile and desktop.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
